# Security policy

## Supported version

Only the current `main` branch and the current GitHub Pages deployment are supported.

## Reporting a security issue

Please report a suspected vulnerability privately by emailing `imsabbirahmed.info@gmail.com` with the subject `Portfolio security report`. Include the affected URL, reproduction steps and likely impact. Do not publish sensitive details before there has been a reasonable opportunity to investigate.

## Security model

This is a static website. It contains no credentials, server-side database or authentication system. The contact form prepares a local email and does not store visitor data. Secrets, private client media, source project files and unlicensed assets must never be committed to this repository.
